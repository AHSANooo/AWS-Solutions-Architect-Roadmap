# Week 3: Custom VPC & Endpoints Lab Guide

Design and deploy a multi-AZ VPC with public/private subnets, NAT gateways, and VPC endpoints.

---

## Lab Objectives

- Custom VPC with CIDR planning
- Public/Private subnet layout
- NAT Gateway configuration
- VPC Endpoints (Gateway & Interface)
- Network ACLs and Security Groups
