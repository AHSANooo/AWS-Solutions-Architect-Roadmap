# Architecture Diagrams

Visual representations of AWS architectures used in labs and cheat sheets.

## Contents

- `/week-01-high-availability/` — Multi-AZ EC2 with EBS and EFS
- `/week-03-custom-vpc/` — VPC architecture with subnets and gateways
- `/week-05-event-driven/` — Event-driven microservices
- `/week-06-disaster-recovery/` — Active-Passive DR topology

## File Formats

- `.drawio` — Editable format (open with Draw.io)
- `.png` — Export for documentation
- `.excalidraw` — Hand-drawn style (open with Excalidraw)

## Export Instructions

1. Open `.drawio` file in [Draw.io](https://draw.io)
2. File → Export As → PNG
3. Save to same directory

---

**Tools:** Draw.io, Excalidraw, AWS Architecture Icons (included in Draw.io)
